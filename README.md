# Gza Dispatch — установка

Приложение для фирмы трансферов и туров: доска диспетчера, туры с водителем и машиной по дням, карта водителей, автопарк (пробег, масло, заправки с фото чеков), паркинги и расходы, расчёт с водителями, Telegram-бот с запросами «Принять / Отклонить», Google Календарь и отчёты в Google Диск. Интерфейс на грузинском, английском и русском.

## Что где лежит

| Сервис | Зачем | Цена |
|---|---|---|
| **GitHub** | код приложения | бесплатно |
| **Vercel** | само приложение (сайт + серверные функции) | бесплатно |
| **Supabase** | база данных, вход, фото | бесплатно (1 ГБ фото) |
| **Telegram-бот** | запросы и напоминания водителям | бесплатно |
| **Google Apps Script** | Календарь и Диск | бесплатно |

## Шаг 1. База данных (Supabase)

1. Supabase → ваш проект → **SQL Editor** → **New query**.
2. Вставьте всё содержимое файла `supabase/schema.sql` → **Run**. Должно быть «Success».
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email** (иначе водителям нужно подтверждать почту, а бесплатный Supabase отправляет всего несколько писем в час).
4. **Project Settings → API**: скопируйте **Project URL** и **anon public key** в файл `js/config.js`.

## Шаг 2. Публикация (Vercel)

1. Vercel → **Add New → Project** → выберите репозиторий `gza-dispatch` → **Deploy**.
2. **Settings → Environment Variables** — добавьте две переменные (это секреты, никому их не пересылайте):
   - `SUPABASE_SERVICE_ROLE_KEY` — Supabase → Project Settings → API → **service_role** key;
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather.
3. **Deployments → … → Redeploy**, чтобы переменные подхватились.
4. Откройте `https://ВАШ-АДРЕС.vercel.app/api/setup` — должно быть `"ok": true`. Это подключает бота к приложению.
5. Supabase → **Authentication → URL Configuration → Site URL**: вставьте адрес приложения (для писем «сбросить пароль»).

## Шаг 3. Напоминания каждые 10 минут

Supabase → SQL Editor → вставьте `supabase/cron.sql`, замените `APP_URL` на адрес приложения (например `https://gza-dispatch.vercel.app`) → **Run**.

## Шаг 4. Первый вход

1. Откройте приложение → **Регистрация**. **Первый зарегистрированный становится владельцем.**
2. Настройки → **Подключить Telegram** — вы будете получать ответы водителей и вечернюю сводку.
3. Добавьте машины (Автопарк) и отправьте водителям ссылку на приложение (Водители → «Ссылка-приглашение»).
4. Водитель регистрируется → вы видите его в «Водители → Новые регистрации» → «Подтвердить водителем» → заполняете его оплату, юрлицо, IBAN.
5. Водитель: «Профиль → Подключить Telegram». С этого момента запросы приходят ему в Telegram с кнопками.

## Шаг 5. Google Календарь и Диск (когда будет нужно)

1. Под Google-аккаунтом диспетчера откройте <https://script.google.com> → **Новый проект**.
2. Вставьте файл `google/Code.gs`, в строке `SECRET` придумайте своё длинное слово.
3. **Начать развертывание → Новое развертывание → Веб-приложение**: «Запуск от имени: я», «Доступ: все» → **Развернуть** → разрешите доступ.
4. Скопируйте адрес (заканчивается на `/exec`) и секретное слово в приложение: **Настройки → Google** → Сохранить → Проверить.
5. Появится календарь **Gza Dispatch** (его можно показать на телефоне в Google Календаре) и папка **Gza Dispatch — reports** с отчётами (каждое 1-е число — отчёт за прошлый месяц, а также кнопка «Сохранить в Google Диск» в Отчётах).

## Как работает запрос водителю

Диспетчер назначает водителя → водителю в Telegram приходит заказ с кнопками **Принять / Отклонить** (и в приложении тоже).
Принял — на доске «Принято». Отклонил — заказ возвращается в «Не назначено», диспетчеру приходит сообщение.
Накануне вечером водитель получает список работ на завтра, за 2 часа — напоминание о трансфере.

## Геопозиция водителей

* Пока приложение открыто — позиция отправляется раз в 1–2 минуты.
* В фоне — через Telegram: в чате с ботом 📎 → Геопозиция → **Транслировать геопозицию** (до 8 часов).
* Постоянный фоновый GPS-трекинг возможен только в нативном приложении (следующий этап).
